## 수정할 곳

- `data.js`: 날짜별 일정, 숙소, 맛집, 장소 검색어, 체크리스트
- `style.css`: 바다색·모래색 테마와 반응형 레이아웃
- `app.js`: 날짜 선택, 식당 필터, 브라우저 저장, 구글맵 연결

지도는 장소 검색 임베드와 Google Maps URL 검색·길찾기를 연결합니다. Maps URLs는 API 키가 필요 없습니다. 지도 임베드 표시가 제한되는 브라우저에서는 구글맵 링크로 장소를 열 수 있습니다. 실시간 Places 평점·자동 경로 계산 API는 사용하지 않습니다. 장소 매칭은 이름과 주소 기반이므로 출발 전 구글맵에서 확인하세요.

공식 Maps URL 문서: https://developers.google.com/maps/documentation/urls/get-started

맛집 저장과 체크는 `localStorage`에 이 브라우저 기준으로만 저장됩니다. 기기 간 동기화 기능은 없습니다. 지도와 웹폰트는 네트워크가 필요하며, PDF의 오프라인 대체재로 모든 기능을 보장하지 않습니다.
